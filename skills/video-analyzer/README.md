# video-analyzer

Скилл Claude Code для локального анализа видео: записи созвонов с клиентами/коллегами и
демо инструментов/конкурентов (файлы или YouTube-ссылки). Всё обрабатывается на машине —
без облака и платных API. По умолчанию собирает **PDF-отчёт**.

Полное описание, схема пайплайна и таблица настроек — в [корневом README](../../README.md).

## Что умеет
- Принимает **локальный видеофайл** или **YouTube-ссылку** (`yt-dlp`).
- Три жанра: **созвон/интервью** (транскрипт + диаризация → продуктовое саммари),
  **демо инструмента** (визуальный разбор экранов), **гибрид** (созвон с шарингом экрана).
- **Умный отбор кадров:** кадр берётся в середине показа (чёткий, не смазанный переход),
  почти-дубли схлопываются, а из контактных листов субагент-скринер отбирает ценные уникальные
  экраны — модель читает в полном разрешении только финалистов.
- **Привязка кадров к речи:** пословный тайминг (`words.json`) → речевой контекст каждого кадра
  (`frames_context.md`), поэтому скриншоты разбираются «в контексте сказанного».
- Транскрипция — **faster-whisper** (пословные таймкоды) + опциональная **диаризация** (pyannote).
- Собирает **PDF-отчёт** (`scripts/make_report.sh`, pandoc → weasyprint): выводы простым языком,
  скриншоты рядом с выводами, для созвона — расшифровка по ролям.
- Опционально: **фокус-режим** (разбор отрезка) и **критический разбор** речи.

## Установка
```bash
bash scripts/setup.sh
```
Поставит `ffmpeg` + `yt-dlp` + `pandoc` + `weasyprint` (Homebrew) и `faster-whisper` + `pyannote`
+ `pillow` (в `.venv`), затем спросит токен HuggingFace для диаризации (бесплатный; нужно один раз
принять условия моделей `pyannote/speaker-diarization-3.1` и `pyannote/segmentation-3.0`). Без
токена скилл работает, но без меток говорящих. `pandoc`/`weasyprint` нужны для сборки PDF.

Затем установи как глобальный скилл (копия в `~/.claude/skills/`):
```bash
cp -R . ~/.claude/skills/video-analyzer
```

## Использование
В Claude Code: «посмотри это видео <путь/URL>», «проанализируй созвон <файл>»,
«разбери этот инструмент конкурента <YouTube-ссылка>», «сделай PDF-отчёт по демо <URL>».

## Структура
```
video-analyzer/
├── SKILL.md                  # инструкция и workflow для Claude
├── DESIGN_frame_selection.md # обоснование content-aware отбора кадров
├── scripts/
│   ├── setup.sh              # установка зависимостей (разово)
│   ├── set-token.sh          # ввод/обновление токена HuggingFace
│   ├── ingest.sh             # YouTube/файл → локальный mp4
│   ├── extract.sh            # кадры (середина показов) + audio.wav
│   ├── plan_frames.awk       # план таймкодов кадров (по показам между склейками)
│   ├── transcribe.sh         # faster-whisper (+ диаризация pyannote)
│   ├── diarize_transcribe.py # транскрипция + диаризация + words.json
│   ├── dedup_frames.py       # дедуп почти-одинаковых кадров (pHash)
│   ├── contact_sheets.py     # контактные листы тамбнейлов для субагента-скринера
│   ├── frame_windows.py      # речевой контекст кадров по таймкодам
│   ├── srt_to_dialogue.py    # черновик диалога по ролям из размеченного SRT
│   ├── make_report.sh        # markdown → PDF (pandoc + weasyprint)
│   └── report.css            # стиль PDF-отчёта
└── README.md
```

## Приватность
Видео и аудио не покидают машину. Токен HuggingFace используется только для разовой загрузки
весов модели диаризации с huggingface.co.
